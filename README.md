# Masfin's Chair

Website for Masfin's hair studio in Calgary. Plain HTML, CSS and JavaScript, no build step. Hosted on GitHub Pages.

## Updating details

- **WhatsApp number:** edit `WHATSAPP_NUMBER` near the top of the script at the bottom of `index.html` (10 digits, no spaces). Every button and number on the page updates from it.
- **Placeholders:** anything in `[square brackets]` in `index.html` is waiting on Masfin.
- **Photos:** the files in `images/` are stand-in artwork. Replace them with real photos (keep the same names, or update the `src` in `index.html`) and remove the "Photo to come" labels.
- **Preview banner:** delete the `<div class="preview">` line at the top of `<body>` when the site is ready.
- **Search engines:** delete the `<meta name="robots" content="noindex, nofollow">` line in `<head>` at launch.

## Welcome wall

The map works on GitHub Pages, but greetings are saved only in each visitor's own browser. A shared wall (everyone sees everyone's pins) needs a small backend later.
